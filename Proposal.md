# Final Project: Hitscan

## Repository
[<Link to my project's public GitHub repository>](https://github.com/CarlosRM07/Final-Project-lab-Hitscan.git)

## Description
My final project for the class I have decided for it to be a interactive game based on aim with your mouse, where you will be able to shoot randomized objects that will be appearing around the screen. This project is relevant to arts and media because shooter games have been in gaming history for a long time, and I will be attempting to implement some of my drawings into the character and maybe some of the targets as well.

## Features
- Feature 1: Randomized Targets
	- Targets will appear all around the screen using Python's `random` module.
- Feature 2: Mouse Shooting and Aim
	- The player will use their mouse to shoot at targets. `Pygame` mouse input and collision will detect if the target was hit or not.
- Feature 3: Custom Artwork
	- I will attempt to implement my own drawings in the program, including the player character and a Game Over screen.
- Feature 4: Score
    - I will implement a score so that we can track how many points the player has.
- Feature 5: Timer
    - A timer to time the player on how much time he has to hit as many targets as he can.
- Feature 6: Target Respawning
    - Once the player hits a target, another target will appear in a completely different location.
- Feature 7: Crosshair instead of Cursor
    - The regular cursor will be replaced by a crosshair that follows the player's cursor.

## Challenges
- Learn how to determine when a target has been hit.
- Create randomized targets while keeping all of them inside the screen.
- How to incorporate my own drawings into an interactive game.
- How to create a countdown timer that makes the game end.
- How to replace the cursor with a crosshair while making the cursor disappear.

## Outcomes
Ideal Outcome:
- A fully functional aim trainer game featuring randomized targets, mouse aiming, a scoring system, Original and Custom artwork, a Game Over screen displaying the final score, and a game that displays a crosshair instead of a cursor.

Minimal Viable Outcome:
- A game where random objects appear, the player can shoot them to make them disappear and get some points, as well as a countdown timer that will make the game end when it reaches 0.
